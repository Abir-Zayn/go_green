Splash Screen Design
--------------------------

Here what has done! First here we have implemented a app logo screen. where an animation will appear and show us the logo of the app.
1500 milliseconds later the app will navigate us to the Splash Screens . SplashScreens has the starter contents of the app. Splash Screens navigator or the page indicator handled by the Controllers
page controllers which will check on what page user is currently on and where they would go next. At the last page of Splash Screen user will see the Get Started button to Login, SignUp.
